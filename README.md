# fontanero-app

A simple web application for plumbing service requests.  
Users can submit their contact information and preferred time to request urgent plumbing assistance.

## Features

- Client form with name, phone number, message, and available time
- Stores requests in MongoDB
- RESTful API built with Spring Boot
- Time zone support (Europe/Madrid)
- Frontend submission via jQuery + AJAX

## Tech Stack

- Java 17
- Spring Boot
- MongoDB
- HTML, CSS, JavaScript (jQuery)
